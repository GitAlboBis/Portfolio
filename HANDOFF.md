## What this is

Single-page, scroll-driven portfolio. **Golden Hour** direction: a light/warm-white page lit by a sunset — ember-led orange + coral/amber/rose, a cool dusk note, and one deep "night" band (Contact/Footer). Type: **Bricolage Grotesque** (display) + **DM Sans** (text). The hero is a raw-WebGPU water letter "A" that reflects a sunset sky.

## Run it

```bash
npm run dev          # http://localhost:3000   (npm only — no bun/pnpm in this env)
npm run typecheck    # tsc --noEmit
# /styleguide        # the live visual contract for the design system
```

A dev-only **leva** panel shows top-right on the home route (tuning knobs for the hero fluid); it is `IS_DEV`-gated and absent in production.

## Architecture (page flow)

`src/app/page.tsx`: **Nav** (+ MenuOverlay) → **#hero** band (fixed WebGPU water "A" + sunset gradient read through it; `CanvasHost` is gated to `/` only) → content on an opaque `bg-paper` layer: **About** → **WorksGallery** (depth gallery) → **Tech sphere** (`TechCloud`) → then the dark band: **Contact** (night) → **Footer**.

- **Scroll backbone:** `src/app/_providers/Smooth.tsx` — Lenis driven by `gsap.ticker` (one loop), reduced-motion guard, exposes `window.__lenis`. Mounted once in `layout.tsx`.
- **State:** `src/store/ui.ts` (zustand) — `locale`, `soundEnabled`, `reducedMotion`, `activeWork`, `loaded`, `menuOpen` (locale/sound persisted).
- **Copy:** `src/content/dict.ts` — EN/IT dictionary (zod-validated), `useDict()`. Never hardcode copy.
- **GSAP:** `src/lib/gsap.ts` — single registration point (ScrollTrigger + SplitText + useGSAP).

## Known issues / gotchas

- **Works projects are PLACEHOLDERS** (`[[TBD]]` in `src/content/works.ts`): Tidewatch/Saltgrid/Lumen/Current. Replace with real projects + add stills via `Work.textureSrc` (planes currently render duotone gradients; `ProjectPlane`/Scene will need a texture branch when images exist).
- **Two GPU contexts** on the home route (WebGPU hero + WebGL works canvas). Fine on desktop; on mobile consider lazy-mounting the works `<Canvas>` and disposing the hero context off-screen.
- **DoF deferred** in the gallery: planes are `transparent`/`depthWrite:false`, so postprocessing DoF won't read their depth. Depth is faked via the mood haze; real DoF needs an opaque pass.
- **Package manager:** repo has `bun.lock` but only `npm` is available here; `simple-icons` was installed via npm (created a gitignored `package-lock.json`).
- Dated docs (`docs/`, `CLAUDE.md`, `IMPLEMENTATION-PLAN.md`) describe the abandoned ocean direction.
