## 2. How Splash actually handles the WAVE (the logic the softening can't replace)

There is **no explicit wave equation** — Splash is a weakly-compressible MLS-MPM fluid and waves *emerge*. Files: `mls-mpm/{p2g_1,p2g_2,updateGrid,g2p}.wgsl`, `mls-mpm.ts`.

- **Injection** (`updateGrid.wgsl`): the mouse impulse is applied **on the grid** (after momentum/mass normalize), as a smooth radial velocity bump — `strength = smoothstep(r², 0, distToCursor²) * 0.2`, direction = mouse *screen velocity* rotated to world, anchored to the real surface cell under the cursor (reconstructed from the depth texture). A still cursor injects nothing; the splash is a **velocity** disturbance proportional to drag speed. Plus constant gravity `vy -= 0.40·dt` every massive cell — the ambient restoring energy.
- **Propagation** (`p2g_2.wgsl`): `pressure = max(0, stiffness·((rho/restDensity)^gamma − 1))` with **stiffness=50, gamma=1**, then `stress = -p·I + viscosity·(C+Cᵀ)` scattered to neighbours as `(-volume·4·stress·dt)·weight·cellDist`. The `·cellDist` factor makes this the **discrete pressure gradient**: a dense cell pushes neighbours *outward*, harder the denser it is. A crest → ring of outward momentum → compresses the next ring next frame → the front walks out cell-by-cell. That stepping **is** the travelling wave.
- **Coherence** (`g2p.wgsl`): **APIC** affine momentum (`C = 4·B`, carried back as `C·dist`) preserves the local velocity gradient across the grid round-trip → fronts stay crisp instead of diffusing into mush. APIC is the main stabilizer (no XSPH, no vorticity confinement).
- **Why stiff + linear = crisp waves:** restoring force per unit over-density is `dp/drho`. With gamma=1 it's large and **constant** (≈ stiffness/restDensity ≈ 16.7) → even a 1% ripple pushes back hard → fast coherent fronts, amplitude-independent speed (no smearing). With our **gamma=5, stiffness=3**, `dp/drho ≈ 0` near rest density → small ripples make no restoring pressure (they diffuse away = mush) and only big compressions snap abruptly (laggy burst). Near-zero bulk modulus for exactly the gentle motions that read as waves.
- **Stabilizers/params:** viscosity **0.1** (tiny, just kills grid-noise), **1 substep** per frame (fewer lossy round-trips = sharper), **no speed cap**, boundaries = **free-slip reflecting** (zero only the normal velocity in the 2-cell shell) + **predictive wall push** (look-ahead `x + v·dt·k`, restoring velocity before breaching) → waves bounce clean.

## 3. Why OURS needles (sim symptom, not a render bug)

The SSF surface is reconstructed from a particle **depth map**; quality is bounded by the input point cloud.

- Splash's stiff incompressible-ish fluid keeps particles at uniform spacing, packed shoulder-to-shoulder → depth map is a continuous sheet → smooth normals → glassy waves.
- Ours: soft EOS (gamma=5/stiffness=3) lets density clump+gap, AND the "A" confinement (medial-axis inflate + leash recall + per-frame **velocity overwrite**) + **speed cap 60** eject thin, fast sheets of a few particles. In the depth map these are isolated points/ribbons → screen-space derivatives produce near-vertical normals at their rims → bright fresnel/specular spikes → a picket fence = **needles**. No depth filter can bridge gaps that have no surface between them.

**→ The needles come from the simulation, not the renderer. Blurring masks them; stiff coherent physics removes the cause.**

## 4. The fix plan (analysed, NOT applied) + the "A" tradeoff

Ordered by leverage. Local files; values to try:

1. **EOS** — `p2g_2.wgsl.ts`: exponent `pow(.,5.) → pow(.,1.)`; `mls-mpm.ts` stiffness `3 → ~50` (back off to ~25 if the surface jitters); `restDensity 4 → 3`. *(biggest lever)*
2. **Viscosity** `0.45 → 0.1` (`mls-mpm.ts`).
3. **Re-add small grid gravity** in `updateGrid.wgsl.ts` (idle else-branch): `vy -= g·dt`, `g ≈ 0.3–0.4`.
4. **Loosen confinement + speed cap** (`g2p.wgsl.ts`): cap `60 → ~120` (or off during interaction); `splashInflate 4.0 → ~1.5`. The per-particle velocity *overwrite* is what scatters the sheets.
5. **Substeps** `2 → 1` (`mls-mpm.ts`), drop the duplicate in-loop `copyPosition`, raise `dt 0.13 → ~0.16–0.20`.
6. **Fixed-point overflow watch:** stiffness 50 increases magnitudes scattered into the `atomic<i32>` momentum accumulators (multiplier `1e7`, ~200k particles). If it saturates, lower the multiplier (e.g. `1e6`).

**Tradeoff:** items 1–4 make Splash's *free, energetic* water — which **will not hold the letter "A"** (a stiff fluid with gravity and no confinement collapses and sloshes). Energetic coherent waves ⟺ readable static "A" are in direct tension; today's confinement exists precisely to suppress the motion these fixes restore.

**Reconciliation — how to get both (the recommended path when we tackle this):** re-express the "A" not as a per-particle velocity overwrite but as a **soft reflecting container**:
- Confine via an **external free-slip boundary at the letter's edge cells** (zero the normal velocity there) + a **predictive push** in `g2p` — exactly how Splash treats its box walls. Waves then reflect cleanly off the *inside* of the letter.
- Replace the medial-axis pull with a **gentle body force added to `v`** (like gravity), scaled down, so the **pressure step dominates** — water sitting in an invisible A-shaped bowl, rippling on its surface.
- **Gate energy by interaction:** calm + contained at rest (soft confinement + mild gravity); on mouse-drag inject Splash's smooth velocity bump so the splash bursts, then the soft container reels it back.

Net: stiff linear EOS + low viscosity + APIC + gravity for real waves, with the "A" as a *soft reflecting container* rather than a velocity override.
