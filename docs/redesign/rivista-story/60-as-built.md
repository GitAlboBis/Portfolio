## C. What a newcomer should not assume

- **The headers of some files tell several versions one over another** (`cover/world.js`, `gallery.js`,
  `field/field.js`): the last note and the code under it are what runs. Some scenes' comments still speak of "the
  wall's grid" (`consult.js`, `evidence.js`, `gallery.js`, `case/figures.js`) and `fx-sound.js` of "the cover's four
  rows": both are gone since wave 7.
- **`web/dist` is a snapshot** the director serves on port 5180; it is rebuilt by hand (`npm run build` in `web/`) and
  holds wave 5's build since 17 November. A lane builds into its own folder.
- **The surface brief** `.impeccable/surfaces/public-proto-rivista-index-html.md` still describes the cover of round 10.
- **The body of `HANDOFF.md`** (§1–§9) describes the site at round 10; its head box is the director's log.
- **`web/release/`** (ignored by git) is the release `web/scripts/release.mjs` writes: the Astro build laid out for the
  root of a domain. It is what Vercel serves; neither `web/dist` nor the assembled pages go online.

tutta un unica esperienza nella home. ovviamente le pagine devono rimanere separate se uno clicca work o dall'url»;

Contact's morning; the cover's index goes; the pages stay separate; the grid goes from every room and a neural cosmos
takes its place. The same evening Alberto asked for SerSan Agent OS (built for SerSan) and Obla (his own project) as
the strongest multi-agent proof, in Consulting, About and Work.
