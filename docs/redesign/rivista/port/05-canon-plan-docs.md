## 1. The rivista canon as a reviewer checklist (u2-canon §1)

### 1.1 Surface and colour
- [ ] One background from header to footer: no section changes background, no tonal bands, no cards. Sections are separated by empty space and hairlines only.
- [ ] Header transparent at rest; `paper-deep` + 1px hairline once scroll passes 24px (0.3s colour transition, not the browser `ease` keyword: see MQ-12).
- [ ] Exactly five neutrals + one accent, with fixed roles: `paper` (the only background) · `paper-deep` (placeholder rectangle under media while loading; header after scroll) · `ink` (headings and base text, never #000) · `graphite` (lead and body) · `stone` (secondary text, labels, legal line, placeholders; still ≥ 4.5:1) · `line` (1px hairlines only, never text) · `accent` (eyebrow, one accent word per chapter, filled CTA, round icon buttons, focus ring, selection, active chip underline / active field line).
- [ ] Counted-accent rule: on any one screen the accent covers at most "one button and one word". It never fills a surface, never colours a paragraph.
- [ ] `accent-dark` only for hover/focus of filled accent surfaces.
- [ ] Selection: accent background, paper text.
- [ ] Dark surfaces: only the preloader panel (and the plan removed even that: "No dark panel in any variant", S1). White text only on accent buttons and on the closing band.

- [ ] `h1, h2, h3, h4 { text-transform: uppercase }` (h1–h3 at 500, h4 at 400); `blockquote` sentence case.
- [ ] The 16px rule: no text below 1rem anywhere; inputs forced to 16px below 768px.
- [ ] The column rule: size follows the column. d1/d2 only on heads that own the full width; in a half column next to media, heads are d2 or d3. Heads stop at 14–28ch; no general `max-width` container.
- [ ] Display tracking 0 on uppercase serif (`display-tight`: `line-height: 0.92; letter-spacing: 0`).
- [ ] Case-page title: `clamp(3rem, 8vw, 9rem)` (u2 §3.2, §6).
- [ ] Lead ≤ 50ch, weight 300, graphite. Measure never exceeds 50ch on a lead, 60ch on body.

### 1.3 Spacing, grid, rhythm
- [ ] Row `padding-inline: 8vw` (115px at 1440), 5vw below 768 (19.5px at 390). No page `max-width`.
- [ ] Chapter `padding-block: clamp(6rem, 14vh, 11rem)` (126px at 900h); mobile `clamp(4rem, 10vh, 6rem)`. More space above a title than below it.
- [ ] Inside a chapter: eyebrow→title 1.5rem · title→lead 2rem · lead→CTA 2rem · block→block `clamp(3rem, 8vh, 6rem)` or `clamp(4rem, 10vh, 8rem)` · title→media `clamp(1.5rem, 4vh, 3rem)` · above first screen `clamp(2rem, 6vh, 4rem)` · step lists `mt-[10vh]`.
- [ ] Grid: two columns from lg (1024), gutter 6vw, asymmetric (`5fr 7fr`, `1.2fr 1fr`, `1fr 1.1fr`, `1.25fr 1fr`, `2fr 3fr`, `1fr 1.2fr`), media and text alternating sides.
- [ ] Lists: 2 cols (md), 3 cols (lg), column gap 3–4vw, row gap 4rem; each item = hairline on top, accent number label (`01`), d3 title, 19px body.
- [ ] Numbered steps `01.`…`09.` at d1 weight 300, d3 title, body.
- [ ] Breakpoints: sm 640 · md 768 (section effects) · lg 1024 (set pieces) · 2xl 1536; motion MQ split 767.98 / 1023.98.
- [ ] Anchors `scroll-margin-top: 6.5rem`.

### 1.4 Media
- [ ] Always the full width of its column or page, fixed aspect ratio, `object-cover`, border-radius 0, no frame, veil, vignette, gradient or caption over it. Sits on a `paper-deep` rectangle while loading.
- [ ] Ratios: `aspect-video` 16:9 for video and the closing band; `aspect-square` for chapter photos; 4/5 for portraits. Rail tiles 4/5, 3/2 or 4/3 at vw widths (phone/tablet/desktop: 78/52/34 · 92/78/63.75 · 92/70/56.67 vw). Review-fix J8 amends: capture tiles are 16:10 at every width, anchored `object-position: left top`; 4:5 only for typographic plates.
- [ ] Parallax on chapter photos `speed -0.04` (±0.56% of own height), linear scrub, half travel below 768.
- [ ] One `priority` image per page (the LCP).
- [ ] Text over an image happens exactly once: the closing band (and in the plan, physics keeps strokes off the letters).

### 1.5 Hairlines, shapes, depth
- [ ] Hairline `1px line`: header after scroll, footer top, legal line, list separators, mobile menu items. Separation by hairline or empty space only.
- [ ] Radius 0 everywhere. Only curve: round icon buttons (play 96, arrows 56, floating 56, social 44, photo controls 44, FAQ "+" 32). A word never goes inside a circle.
- [ ] No shadows, no blur, no glass, no gradients.
- [ ] Focus: `outline: 2px solid accent; outline-offset: 3px`; fields have no ring, their bottom line turns accent.
- [ ] Depth only from scale and two-plane motion (rail moves, photos pan the other way).

### 1.6 Components
- [ ] Chapter head cell: eyebrow (accent label with `::before` dash 1.75rem × 1px, opacity 0.6, gap 0.5rem) → d1/d2 uppercase title → optional one ornamental accent word (`aria-hidden`, indented 14–24vw, overlapping the last line by about −0.4em; mobile −0.12em / 40vw per A12) → graphite lead ≤ 50ch → ghost link. Left-aligned; one chapter per page may be right-aligned (review-fix J6: Work is that chapter).
- [ ] Buttons: inline-flex, gap 0.6rem, label 1rem/600/uppercase/0.08em, lh 1.2, transitions .25s, min-height 2.75rem on coarse pointers, trailing ArrowUpRight 1.1em (stroke 1.4). `cta-solid` (accent fill, white text, 1.5px accent border, padding `1.05rem 2rem`, accent-dark on hover): one per screen. `cta` outline. `ghost`: no box, padding `0.4rem 0`, ink, underline 1.5px, offset 0.35em, accent on hover.
- [ ] Inline links: `.link-underline` (background-size 0→100% × 1.5px, 0.4s expo) or `.link-draw` (::after scaleX 0→1, 0.35s, origin left).
- [ ] Fields: no box, 1px ink bottom line, padding `0.75rem 0`, 19px, label above in stone. Chips/tabs: uppercase stone labels, min-height 2.75rem, 2px transparent bottom line, selected = accent line + ink text (`aria-pressed`).
- [ ] Header ≥ lg: height `clamp(5rem, 12vh, 7.5rem)`, not sticky, two rows. Below lg: sticky, "MENU / CLOSE" underlined word, full-screen paper panel with d2 uppercase items separated by hairlines. (Plan §5 adds: five paper columns descending from the right, index numbers, email at lead size, LinkedIn, GitHub, EN / IT.)
- [ ] Footer: in flow, hairline on top, padding-top `clamp(4rem, 10vh, 7rem)`, columns `1.4fr 1fr 1fr 1fr` gap 3rem, heads d4 300 uppercase, lists 19px, legal line 16px stone, safe-area bottom.
- [ ] Mobile action bar (< 640): fixed paper bar, hairline top, full-width `EMAIL` CTA.

### 1.7 Motion vocabulary and timing tokens
- [ ] Eases: `--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1)` · `--ease-soft: cubic-bezier(0.32, 0.72, 0, 1)` (canon) · `--ease-domus: cubic-bezier(0.22, 0.9, 0.36, 1)` (CustomEase `domus` = `M0,0 C0.22,0.9 0.36,1 1,1`) · `domus.inOut` = `M0,0 C0.66,0 0.22,1 1,1` · `dtOut 0.25,1,0.5,1` · `dtHorScroll 0.25,0,0.75,1`. The plan then collapses these to one family (§3 below).
- [ ] Durations: micro 0.3 · short 0.6 · reveal 0.9 · hero 1.4 · transition 1.1. Staggers: chars 0.06 · words 0.10 · lines 0.11 (TextLines actually uses 0.09) · cards 0.12. Rise distance 48px (never 100+); Reveal uses 2.5rem.
- [ ] Gesture 1 Lines from a mask: SplitText `type: "lines", mask: "lines"`, `yPercent 112 → 0`, 1.05s `expo.out`, stagger 0.09, trigger `top 86%`, `toggleActions: "restart none none reverse"`, `autoSplit`, split after `document.fonts.ready`, `aria: "none"`. Exit: `yPercent → −110`, 0.4s `power2.in`, stagger/2.
- [ ] Gesture 2 Fade-up: opacity 0→1, `translateY(2.5rem)→0`, 0.9s ease-out-expo, IO threshold 0.12, rootMargin `0 0 -8% 0`, reversible, delays 80–200ms, 2.5s safety timer, `will-change` only while hidden (MQ-10 amends: only within 20% of the viewport, removed on transitionend).
- [ ] Gesture 3 Parallax: scrub, transform only, `speed × 14` yPercent, half below 768.
- [ ] Rail (`runway 120`): ≥1024 + motion allowed, sticky track in a corridor, `ease: none`, `scrub 0.6`, media pan ±4% (plan: ±6%, then J8 ±2.5% for captures); below 1024 native horizontal scroll with snap, CSS `--rail-p`, 2px × 4rem progress indicator.
- [ ] Rotating mark: 60 ticks + monogram, 30°/s, `30 + 10·|v|` in 0.3s, back in 1.1s; 44px in header from lg.
- [ ] Preloader: once per session (sessionStorage), never with reduced motion or a URL hash, skipped by tap/key, CSS-driven with a JS failsafe.
- [ ] Rules: animate only transform, opacity, clip-path; every animation inside `gsap.matchMedia("(prefers-reduced-motion: no-preference)")`; hidden states set only by JS (text always in the initial HTML); no transforms on ancestors of sticky/fixed; one Lenis on the GSAP ticker with `ScrollTrigger.config({ ignoreMobileResize: true })`; hidden states containing links use `opacity` + `pointer-events:none` (+ `inert`), never `autoAlpha`. Never GSAP `pin`: CSS `position: sticky` on a tall runway (u1 §0.4).
- [ ] Domus refused page transitions and a custom cursor; Alberto wants transitions: they are the main extension (u2 §3.3, plan S4/S5).

### 1.8 Mobile rules
- [ ] 5vw gutter (19.5px at 390); d1 falls to the 38px clamp floor (3–4 line heads); lead 21.6px dominates.
- [ ] Never stack two fixed circles bottom-right; one action bar only.
- [ ] Rail = native horizontal scroll with snap + CSS pan + 2px progress + index shown.
- [ ] S1 mobile: counter and sheet roll-up only; docked plate opens from a slit; never over 2.5s. S3 stage off below 1024. Menu: columns from the right, stagger 30. Touch targets ≥ 44px (A10; the switcher tab may be 24×44 on phones per WCAG 2.5.8).
- [ ] No horizontal overflow at 390, 768, 1024.

### 1.9 Reduced-motion rule
- [ ] The page stays beautiful when frozen: reduced motion = a complete static page, final state of every reveal with no tween, no text below 0.95 opacity, all figures printed, rules drawn, rail as a static (three-column, A7) grid, no preloader, S4 = 150ms opacity cover/uncover, S5 = 200ms, menu 150ms opacity, band = still frame on clean paper, cursor / magnetic / nav roll off. Lenis is destroyed under reduce (native scroll), and a live change of the preference reloads or re-syncs.

### 1.10 Do / Don't (verbatim spirit)
Do: one background · viewport-measured uppercase titles, lh 0.92–0.95 · same chapter cell everywhere · accent only for accents and conversion · media full width, square-cornered, on paper-deep · all text ≥ 16px · hairlines and empty space as the only separators · every animation reversible and inside motion-ok · beautiful when frozen.
Don't: radii (except round icon buttons) · shadows, blur, gradients, veils, vignettes · cards, boxes, pills · dark surfaces · text below 16px · more than one ornamental accent word per chapter, or one over a photo · d1/d2 in half a column · extra pinned sections beyond the registered set pieces · flowers or drawn ornaments · stats without a source. Page length: aim 10–14 viewports on `/` (plan budget ≤ 15.5 at 1440x900; integrator measured 14.80 in V1).

## 3. Signature moments S1–S5 as acceptance criteria, section table, global rules

Ease names (plan header): **out** = `cubic-bezier(0.16,1,0.3,1)` (`expo.out`) · **io** = `cubic-bezier(0.66,0,0.22,1)` (CustomEase `domus.inOut`) · **soft** = `cubic-bezier(0.22,0.9,0.36,1)` (`domus`) · **xio** = `cubic-bezier(0.87,0,0.13,1)` (`expo.inOut`) · **exit** = `power2.in` · **lin** = linear, scrubs only.

Thesis (plan §1): "Ink, cut, measure … One ease family for the whole site (out for entrances, io for travel, lin for scrubs) … If a motion is not ink, a cut or a measurement, it is not in the site."

### S1 "Registro" (preloader to hero handoff)

Must not: show the big name inside the preloader; any ghost of hero text through the sheet; a trail restart when the window lands; a layout shift when the sheet goes; block over 5.2 s; appear on a repeat visit, with a hash, on arrival, or with reduced motion."

### S2 "Carta corrente" (hero visual)

Fallback: real `<img>` poster per variant (`fx-plate-v1.webp`), caption "Still frame captured from this engine"; `html.gl-off` turns S3 off. **Port note:** the production hero in `CLAUDE.md` is the WebGPU MLS-MPM bench; the prototype's flow field is the WebGL2 stand-in. ## 6. Library constraints from Context7 (verified unless marked)

### (a) Next.js 16 App Router — `/vercel/next.js/v16.2.9` (installed 16.2.10)
1. **template.tsx vs layout.tsx.** Doc: "unlike layouts that persist state across routes, templates are assigned a unique key, causing child Client Components to reset their state upon navigation." Source: `layout-router.tsx` wraps in `<TemplateContext.Provider key={stateKey}>`. Consequence: put the persistent chrome (Lenis provider, header, AT ring, S4 overlay, S5 columns, the single GL canvas host) in `layout.tsx`; put per-route enter/exit (TextLines of the page d1, `fx:ready` emit) in `template.tsx` so it re-runs on every navigation. Layouts "don't re-render on navigation" (Partial Rendering), so a layout-level effect will not fire per route: subscribe to `usePathname()` in a client child instead.
2. **Link scroll and programmatic scroll.** Doc: "Setting `scroll` to `false` prevents Next.js from attempting to scroll to the first page element upon navigation." `router.push(href, { scroll?: boolean, transitionTypes?: string[] })`: "If `false`, the page will not scroll to the top after navigation. Defaults to `true`." Snippet:
```tsx
<Link href="/work/sersan-io" scroll={false} onNavigate={(e) => { if (locked) e.preventDefault(); }} />
router.push('/work', { scroll: false })
```
`onNavigate` is "cancellation only": it "can only call preventDefault() to cancel navigation". So the S4/S5 interception is: `onNavigate` → preventDefault → run cover → `router.push(href, { scroll: false })` at the commit point → set scroll yourself with `lenis.scrollTo(y, { immediate: true, force: true })`. Back/forward: "App Router has its own back/forward scroll restoration" (`FreshnessPolicy.HistoryTraversal: // Back/forward — scroll restoration is handled separately.`), so for the S4 flip-back the port must override with its own restore (`rv-origin` y + railP) after the router's, i.e. after the new tree commits and `ScrollTrigger.refresh()`.
3. **Smooth-scroll override.** Doc (v16 upgrade guide): "In Next.js 16, the framework no longer overrides your `scroll-behavior` CSS setting during navigation by default… you must add the `data-scroll-behavior="smooth"` attribute to your `<html>` element." Snippet: `<html lang="en" data-scroll-behavior="smooth">`. Add `scroll-padding-top` on `html` for the sticky header offset.
4. **Prefetch.** Doc: "The `prefetch` prop defaults to `auto` or `null`, prefetching static routes fully… Setting `prefetch` to `true` fully prefetches all routes, while `false` disables prefetching entirely." "Prefetching is only enabled in production." Hover-only pattern: `prefetch={active ? null : false}` with `onMouseEnter={() => setActive(true)}`; manual `router.prefetch('/work/slug')` on `pointerenter`/`focus` (this replaces the prototype's `<link rel=prefetch>` from MQ-03). All 9 case routes are static (SSG), so default prefetch already covers the S4 seam.
5. **next/font/google, two families.** Doc snippet (adapted to V1):
```tsx
import { Cormorant_Garamond, Figtree } from 'next/font/google'
const display = Cormorant_Garamond({ subsets: ['latin'], weight: ['500','600'], style: ['normal','italic'], variable: '--font-display', display: 'swap' })
const text = Figtree({ subsets: ['latin'], variable: '--font-text', display: 'swap' }) // variable font: weight may be omitted
<html lang="en" className={`${display.variable} ${text.variable}`}>
```
Doc: "If loading a variable font, you don't need to specify the font weight"; `weight` "is required if the font being used is not a variable font" (Cormorant Garamond on Google is static weights → list them; Figtree is variable). `adjustFontFallback` "For `next/font/google`, it's a boolean (default `true`)" → the metric-matched fallback that D4 hand-built comes for free; keep it on. Fonts are self-hosted by next/font (satisfies A9). Tailwind v4: expose through `@theme { --font-display: var(--font-display); }` in `globals.css` (the doc's tailwind.config snippet is v3; v4 is CSS-first).
6. **next/image static WebP with priority.** Doc: static import gives width/height/blurDataURL automatically; responsive: `sizes="100vw"` + `style={{ width: '100%', height: 'auto' }}`. Canon: one `priority` image per page (the LCP), on a `paper-deep` box with a fixed aspect ratio. Snippet:
```tsx
import sersan from '@/../public/captures/sersan-io.webp'
<Image src={sersan} alt="…" priority sizes="(min-width:1024px) 34vw, 78vw" style={{ width:'100%', height:'auto' }} />
```
7. **generateStaticParams + params as Promise.** Doc: `export async function generateStaticParams() { return [{ slug: '1' }, …] }` and `export default async function Page({ params }: PageProps<'/work/[slug]'>) { const { slug } = await params … }`; opengraph-image also receives `params: Promise<{ slug: string }>`. Per-route `generateMetadata` reads the dict server-side.
8. **'use client' boundaries.** Doc: a Server Component layout can import and render Client Components; Server Components can be passed as `children` into Client Components (`<Modal><Cart/></Modal>`); `useRouter`, `usePathname`, `useSearchParams` "are only supported in Client Components"; `useSelectedLayoutSegment` "is usually called via a Client Component that is imported into a Layout". A plain data module (`dict.ts`, `works.ts`) can be imported by both sides as long as it has no `'use client'` directive and exports only serializable data; the locale-dependent `useDict()` hook stays client-only, while server pages/metadata read `dict[locale]` directly. Not explicitly stated by the docs for shared data modules: mark as inferred.

### (b) React 19.2 — `/reactjs/react.dev` (installed 19.2.7)
1. **StrictMode double invoke.** Doc: "When Strict Mode is on, in development, React runs setup and cleanup one extra time before the actual setup… The cleanup function should stop or undo whatever the setup function was doing." Consequence: every GSAP/Lenis/GL effect must be fully reversible (kill ticker callback, `lenis.destroy()`, `ctx.revert()`, `split.revert()`, GL `sleep()`/context release); session flags like `rv-intro-seen` must be set at the handoff, not at mount, or the second mount will skip the intro. Animation pattern from the doc: create in effect, `return () => animation.stop()`.
2. **ref as prop.** Doc: "In React 19, `forwardRef` is no longer necessary. Pass `ref` as a prop instead." Snippet: `function MyInput({ ref }) { return <input ref={ref} /> }`. Use this for `Field`, `Media`, `TextLines` wrappers that need the DOM node for `useGSAP` scope.
3. **useSyncExternalStore for matchMedia.** Doc: `useSyncExternalStore(subscribe, getSnapshot, getServerSnapshot?)`; "`getServerSnapshot` … runs on the server when generating the HTML [and] on the client during hydration… Must return identical data on server and client. If omitted during server rendering, an error is thrown." Snippet for reduced motion / fine pointer:
```ts
const mq = () => window.matchMedia('(prefers-reduced-motion: reduce)')
export const useReducedMotion = () => useSyncExternalStore(
  (cb) => { const m = mq(); m.addEventListener('change', cb); return () => m.removeEventListener('change', cb) },
  () => mq().matches,
  () => false) // server + hydration: motion on, then flip after hydration (no mismatch)
```
This replaces the store round-trip in `Smooth.tsx` for read-only consumers; the `data-motion="reduced"` html attribute stays for CSS.
4. **ViewTransition status.** Doc: "The `<ViewTransition />` API is currently only available in React's Canary and Experimental channels." Local check: `grep ViewTransition node_modules/react/cjs/react.production.js` → 0 matches in 19.2.7. Next's `router.push(..., { transitionTypes })` exists but is only meaningful with the canary API. Verdict: not available for the port; cross-document/DOM View Transitions could be a CSS-only progressive enhancement (`@view-transition { navigation: auto }` is irrelevant in an SPA), so S4/S5 stay GSAP-driven.

### (c) GSAP 3.15 + @gsap/react 2.1.2 — `/greensock/react`, `/websites/gsap_v3`, `/greensock/gsap-skills`
1. **useGSAP.** Register once: `gsap.registerPlugin(useGSAP)` (already the pattern in `src/lib/gsap.ts`). Config: `useGSAP(() => {…}, { dependencies: [endX], scope: container, revertOnUpdate: true })`.
