01 What it is

Ten actors,a single chain

A multi-actor platform modelling an agricultural supply chain with 10 roles (producers, curators, animators, buyers), built as the Software Engineering exam project by a team of 3.

02 The method

Requirementsto code

  1. 01The Unified Process, from requirements and use-case modelling to a layered Spring Boot implementation.
  2. 02MVC, Repository and Service Layer, GRASP principles.
  3. 03JWT-based RBAC on Spring Security.
  4. 04Gang-of-Four design patterns throughout.
  5. 05A relational PostgreSQL schema linking producers, products, certifications, events and marketplace orders, exposed through REST APIs with geographic search.
  6. 06Documented with full UML artefacts.
