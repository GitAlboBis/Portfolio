01 What it is

Families, caregivers,in real time

A production PWA that matches families with home-care caregivers across the Italian domiciliary-care market, architected and shipped on Next.js 15 App Router, React 19, TypeScript strict and Supabase.

Stack

  • Next.js 15
  • React 19

  • Web Push (VAPID)
  • Leaflet
  • Sentry
  • GitHub Actions

02 What it does

Offline, live,on the map

  1. 01Full offline support through a custom Service Worker (Serwist), with VAPID-signed Web Push notifications.
  2. 02Real-time messaging between families and caregivers on Supabase Realtime (WebSocket), with integrated push.
  3. 03Sub-second geospatial caregiver search on PostGIS 3 (GiST indexes, WGS-84 geography), with Leaflet maps and open-source geocoding (Photon and Nominatim): no paid map API.

03 Security

Hardenedend to end

  1. 0

    Known auth vulnerabilities at launch

    Row-Level Security on every sensitive table, RBAC middleware, HSTS, a restrictive CSP whitelist and VAPID-signed push.

  2. 3

    Runtime layers under Sentry

    Client, server and edge, with a tunnel route that bypasses ad-blockers.

Plus a localised Italian and English admin dashboard for caregiver identity verification, server-side image optimisation with Sharp, and automated CI/CD on GitHub Actions.
