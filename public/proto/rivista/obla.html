Obla

Obla is my personal multi-agent system: one chief of staff I talk to, and the agents it hands the work to, instead of opening sessions, writing prompts and checking on things by hand. It lives on my desktop, runs on my own machine and answers to me alone.

Personal project

  1. 01

    It listens

    I say its name, or hold a key, and speak. The wake word and the voice chain run locally.

  2. 02

    It thinks

    A small local model answers closed questions, such as which agent takes a job; a second one holds the conversation; only real work goes to Claude Code.

  3. 03

    It works

    Each job goes to the agent that fits it, for code, design, research, content or review: a Claude Code session on the right repository, with the brief already written. The agents hand work on to each other, within limits written in code.

  4. 04

    It asks

    Models propose, code acts: a push, a merge or a deletion waits for my yes on an approval card, and a message to someone else stays a draft until I send it.

  5. 05

    It reports

    Every morning at 08:00: jobs, sessions, approvals, spending and what each agent did, spoken or written. What it remembers is kept in Markdown notes I can read and edit.

Runs on
Windows, TypeScript on Node.js, Rust and Tauri, llama.cpp with local models, the Claude Agent SDK and MCP, SQLite, Obsidian
For
One person. Not distributed.
