02 · Sphere AI

It asksbefore it guesses

Sphere AI is the bilingual (IT/EN) RAG mentor inside SphereNode. It answers only from the proprietary curriculum: semantic chunking and embeddings in pgvector, tier-aware retrieval with a curated fast path for canonical answers, and an LLM relevance grader on top.

The guardrails behind the numbers

  1. 01Asks for clarification instead of guessing.
  2. 02Refuses questions built on a false premise or asking for unsafe actions.
  3. 03Requires live evidence before answering anything time-sensitive.
  4. 04Never lets static FAQ content stand in for current market information.
  5. 05Reads the Trading Journal only as a consent-gated, owner-only source, personal data excluded by default.

03 · Reliability

What hadto holdat launch

A paywalled product with tiered access, live video, recurring payments and scheduled jobs, where a single defect leaks paid content or strands paying customers.

  1. 5

    Revenue-critical defects closed

    The payments-to-entitlement pipeline rebuilt as a tested state machine: access surviving cancellation, disputes and unknown events defaulting to open, empty lookups downgrading paying users, duplicate rows stranding paid customers, out-of-order events resurrecting revoked access.

  2. 6

    Access-control defects closed before launch

    Among them a tier leak exposing 206 live sessions and 79 transcripts to free accounts, alongside a 33-finding security audit remediated in one batch.

  3. 21

    Silent scheduled jobs

    Dead for weeks while every dashboard still reported success. Root-caused, then the missing monitoring and alerting built so it cannot go unnoticed again.

  4. 21/49

    Production releases as release manager

    Including the public launch. Plus the live-session video pipeline on Cloudflare Stream and the Trading Journal analytics engine.
